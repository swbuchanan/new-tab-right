# new-tab-right
Extension for Chromium-based browsers (I have only tested it on Brave) that opens all new tabs immediately to the right of the current tab.

It should require no configuration and should work regardless of the way that you open a new tab (with right click menu, a different shortcut, etc.).

# Installation

1) Clone the github repository or just download `manifest.json` and `service_worker.js` to some folder.
2) Open your browser's extensions page. There should be a button `Load Unpacked` or something similar. Click on this and select the folder where you saved the files.
3) Enjoy your new optimized and organized lifestyle.
